# Lucky Draw Lottery Game

## Overview
The Lucky Draw Lottery Game is an interactive game that allows users to enter a lottery and win exciting prizes. Designed with user engagement in mind, this project showcases a simple yet effective interface that enhances the gaming experience.

## Features
- **User Registration**: Seamless registration process for players.
- **Lottery Entry**: Users can enter the lottery by purchasing tickets.
- **Draw Mechanism**: Randomized selection of winners ensuring fairness.
- **Prize Distribution**: Quick and efficient prize distribution to winners.
- **Admin Dashboard**: For managing users and monitoring lottery activity.

## How to Use
1. **Clone the Repository**:  
   Use the following command to clone the repo:
   ```bash
   git clone https://github.com/736205-ux/Luck-game
   ```  
2. **Install Dependencies**:
   Navigate to the project directory and install the required dependencies:
   ```bash
   npm install
   ```  
3. **Start the Application**:
   Run the application using:
   ```bash
   npm start
   ```  
4. **Create an Account**:  
   Navigate to the registration page and create a user account.
5. **Enter the Lottery**:  
   After registration, users can purchase lottery tickets to enter the game.

## Technical Details
- **Technology Stack**:  
   - Frontend: React.js  
   - Backend: Node.js with Express.js  
   - Database: MongoDB  
- **API Endpoints**:  
   - `POST /api/register`: For user registration.
   - `POST /api/enter`: For entering the lottery.
   - `GET /api/winners`: To retrieve winners of the lottery.
